# stend

Здесь лежит список источников подписок для программы Stend: откуда она берёт адреса серверов.

Раньше этот список был только внутри программы. Когда источник умирал или появлялся новый, приходилось собирать и раздавать новую версию. Теперь программа сама скачивает `sources.txt` отсюда и берёт его, если он свежее того, что в ней вшит.

## Как программа проверяет список

Последняя строка файла — подпись ed25519 всего, что выше. Открытый ключ вшит в программу, закрытого здесь нет. Список с неверной подписью программа выбросит, откуда бы его ни скачала. Список старше того, что у неё уже есть, тоже не возьмёт.

Поэтому репозиторий — просто место хранения. Если кто-то положит сюда свой файл, ничего не изменится, пока у него нет ключа.

## Откуда программа его скачивает

- `raw.githubusercontent.com/dadanobel/stend/main/sources.txt`
- `cdn.jsdelivr.net/gh/dadanobel/stend@main/sources.txt`
- `dadanobel.github.io/stend/sources.txt`

Все три адреса запрашиваются одновременно, берётся самый свежий проверенный ответ. Если GitHub недоступен напрямую, программа повторяет попытку через свой туннель, когда тот заработает. Если не вышло ничего, она работает с последним сохранённым списком или со вшитым.

## Формат

```
stend-sources 1 <дата в UTC>
<уровень> <w или -> <адрес подписки> [зеркало ...]
...
sig <подпись>
```

- Уровень 1 — источники, проверенные из России, их программа пробует первыми. Уровень 2 — большой общий список. Уровень 3 — запас. Уровни идут по порядку.
- `w` — источник собран под белые списки операторов. Это влияет только на подписи в журнале программы.
- Зеркала — другие адреса того же файла. Их пробуют, только если основной адрес не ответил.
- Строки с `#` — комментарии.
